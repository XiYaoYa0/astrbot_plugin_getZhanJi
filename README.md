# 三国杀战绩查询插件

一个 AstrBot 插件：抓取 [群英战报](http://124.223.83.131:5000/) 的三国杀战绩网页，解析全部对局，并提供指令查询和自然语言问答。

## 功能

- 总览：对局数、时间范围、积分榜、武将出场榜、全员身份分布
- 玩家统计：场次、胜负平、胜率、总积分、身份分布、常用武将
- 武将统计：出场、胜率、身份分布、常用玩家
- 组合分析：某玩家使用某武将时的身份分布，并给出「最可能身份」
- 玩家画像：读取 `player_profiles.json` 中手动维护的性格/打法备注，并叠加自动计算的场均伤害、击杀、承伤、恢复、存活率等客观风格指标
- 最近对局：按时间倒序列出最近的牌局
- 自然语言：注册了 LLM 工具 `sanguosha_zhanji`，可以直接 @机器人 提问
- 本地缓存：默认缓存 10 分钟，避免频繁抓取网页

## 指令

| 指令 | 说明 |
| --- | --- |
| `/zhanji` 或 `/战绩` | 战绩总览 |
| `/zhanji 玩家 <昵称>` | 玩家统计 |
| `/zhanji 武将 <武将>` | 武将统计 |
| `/zhanji <昵称> <武将>` | 该玩家用该武将时的身份分布 |
| `/zhanji 最近 [数量]` | 最近对局，数量 1-10，默认 5 |
| `/zhanji 刷新` | 强制重新抓取网页 |
| `/zhanji help` | 帮助 |

示例：

```text
/zhanji ranber 孙权
/zhanji 玩家 ranber
/zhanji 武将 孙权
/zhanji 最近 3
```

名称支持精确匹配、唯一子串匹配和模糊推荐。例如输入 `ranber`、`Ranber` 都可以；搜索范围通常会覆盖全部历史对局。

## 自然语言问答

插件注册了一个 LLM 函数工具 `sanguosha_zhanji`，参数为：

- `player`：玩家昵称，可留空
- `general`：武将名称，可留空
- `days`：只统计最近多少天，`0` 表示全部历史，不填则使用插件默认值

当用户 @机器人 问类似下面的问题时，AstrBot 的大模型会调用工具取数再回答：

```text
ranber 用孙权时最可能是什么身份？
最近谁胜率最高？
孙权在哪些身份下胜率最高？
```

> 自然语言问答需要 AstrBot 已配置并启用对话大模型。模型只负责组织和解释数据，具体战绩由网页实时抓取。

## 玩家画像（性格 / 打法风格）

玩家画像保存在 AstrBot 的持久插件数据目录：

```text
data/plugin_data/astrbot_plugin_getZhanJi/player_profiles.json
```

在 D 盘部署的机器人中，完整路径是：

```text
D:\qqaibot\astrbot\data\plugin_data\astrbot_plugin_getZhanJi\player_profiles.json
```

插件首次加载时会从插件目录的 `player_profiles.json` 模板自动复制一份；模板里已经列出当前全部玩家。**插件目录里的那份只是初始化模板，日常编辑请改持久目录里的文件，升级插件不会覆盖它。**

```json
{
  "ranber": {
    "personality": "性格直爽，爱开玩笑，输了会复盘",
    "style": "打法偏激进，喜欢主动开团，偏爱孙权、黄忠",
    "notes": "群里老玩家，常坐 6 号位"
  }
}
```

- `personality`：性格特点
- `style`：打法风格
- `notes`：其他备注（口头禅、习惯位置等）

三项都可以留空，留空则不显示。**保存文件后插件会按修改时间自动重载，不需要重启。** 玩家名使用战绩网页里的原始昵称（不是 QQ 昵称）。

画像会和插件自动统计的「数据风格」一起展示：场均伤害、击杀、承伤、恢复、存活率、平均回合。主观画像与客观统计会分开标注；LLM 工具也会分别返回 `profile` 和 `style_metrics`，避免把主观印象当成统计事实。

## 数据说明

- 数据源：`http://124.223.83.131:5000/`，抓取时间范围为全部历史，按每页 100 局分页读取。
- 身份：主公、忠臣、反贼、内奸。
- 胜率 = 胜场 / 出场，平局计入出场但不计胜场，与网页口径一致。
- 网页中的 2 人局（1v1）也会被统计；输出中会显示对局规模。
- 网页本身已排除机器人对局（昵称包含 COMP 的整局），插件不重复过滤。
- 同名玩家按网页原始昵称区分，不合并小号。

## 配置

在 AstrBot 管理面板的插件配置中可修改：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `base_url` | `http://124.223.83.131:5000/` | 战绩网页地址 |
| `cache_ttl` | `600` | 缓存秒数，0 表示每次重抓 |
| `timeout` | `20` | 单页请求超时秒数 |
| `default_days` | `0` | 默认统计最近多少天，0 为全部历史 |
| `max_pages` | `50` | 最多抓取页数 |

## 实现说明

- 仅使用 Python 标准库（`urllib` + `re` + `html`），不需要额外安装依赖。
- 网络请求通过 `asyncio.to_thread` 放到线程中执行，不阻塞 AstrBot 事件循环。
- 解析目标是网页中的 `details.game-card` 卡片和 `table.battle-table` 表格；如果网站改版，需要同步调整 `main.py` 顶部的正则。
- 数据会缓存在内存中；重启 AstrBot 后首次查询会重新抓取。
